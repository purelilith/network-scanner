# NetworkScanner

Android-приложение для сканирования локальной Wi-Fi сети: находит устройства, подключённые к той же сети, что и телефон, и пытается определить их тип по открытым портам.

## Что умеет

- Сканирует подсеть (254 адреса) и находит "живые" устройства через ICMP-пинг
- Для каждого найденного устройства проверяет несколько популярных портов (80, 22, 8080, 9100, 8009) и делает предположение о типе устройства (роутер, принтер, Chromecast и т.д.)
- В некоторых домашних сетях показывает имя хоста, которое дает понять, что это за устройство (iPhone, ноутбук, андроид телефон и т.п.)
- Показывает список найденных устройств с временем последнего скана
- Поддержка pull-to-refresh для повторного скана

## Стек

- Kotlin
- Jetpack Compose (Material3)
- Kotlin Coroutines
- MVVM (ViewModel + StateFlow)

## Статус

Pet-проект, в активной разработке.

## Как запустить

1. Клонировать репозиторий
2. Открыть в Android Studio
3. Запустить на реальном устройстве, подключённом к Wi-Fi (эмулятор не покажет реальные устройства сети)
